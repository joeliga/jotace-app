# JOTACE - Centro Académico y Servicios de Papelería

Aplicación Web desarrollada con **Next.js**, **Tailwind CSS** y **Supabase** como parte del Examen Integrador.

## Características Principal
- **Autenticación:** Registro e inicio de sesión de usuarios con Supabase Auth.
- **Buscador Interactivo:** Filtro en tiempo real para servicios de matemáticas, tareas e impresiones.
- **Gestión de Solicitudes (CRUD):** Creación, visualización, cambio de estado y eliminación de pedidos.
- **API Externa:** Consumo de la API de REST Countries.
- **Vistas por Rol:** Panel de cliente (`/dashboard`) y panel de administración (`/admin`).
